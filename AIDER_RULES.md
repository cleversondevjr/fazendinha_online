# REGRAS PERMANENTES DO PROJETO FAZENDINHA ONLINE

## Idioma

- Responder sempre em português do Brasil.

## Escopo

- Trabalhar somente nos arquivos adicionados ao chat.
- Nunca alterar arquivos fora da tarefa solicitada.
- Nunca fazer refatorações sem autorização.

## HTML

- Nunca utilizar style="".
- Nunca colocar CSS inline.

## CSS

- Toda alteração visual deve ficar no style.css.
- Preferir criar novas classes CSS.
- Nunca remover regras existentes sem explicar o motivo.

## JavaScript

- Preservar toda lógica existente.
- Nunca alterar APIs ou backend sem autorização.

## Fluxo obrigatório

1. Explicar rapidamente o plano.
2. Informar quais arquivos serão modificados.
3. Aguardar autorização.
4. Executar apenas a tarefa solicitada.
5. Explicar exatamente o que foi alterado.
6. Encerrar a tarefa e aguardar nova autorização.

## Importante

- Nunca criar commits automaticamente.
- Nunca avançar para outra parte do projeto por iniciativa própria.
