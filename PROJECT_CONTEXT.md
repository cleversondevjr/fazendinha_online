# CONTEXTO DO PROJETO - FAZENDINHA ONLINE

## Objetivo

Este projeto é um jogo web chamado Fazendinha Online.

O objetivo é evoluir o projeto sem quebrar funcionalidades existentes.

## Regra principal

Nunca modificar partes não relacionadas à tarefa solicitada.

## Estrutura

Frontend:
- login.html
- index.html
- style.css
- script.js
- assets/

Backend:
- server/

Banco:
- migrations/

## Forma de trabalho

Trabalhar sempre por módulos.

Exemplos:
- Login
- Interface
- Plantação
- Marketplace
- Inventário
- Administração
- Ranking

Nunca alterar mais de um módulo por tarefa.

## Alterações

Antes de editar:

1. Explicar rapidamente o plano.
2. Informar quais arquivos serão modificados.
3. Aguardar autorização.

Depois de editar:

1. Explicar exatamente o que foi alterado.
2. Não continuar para outra tarefa.

## CSS

Toda alteração visual deve permanecer no style.css.

Nunca usar CSS inline.

## HTML

Nunca utilizar style="".

## JavaScript

Preservar toda lógica existente.

Nunca refatorar código sem autorização.

## Backend

Nunca alterar APIs, banco ou rotas sem autorização explícita.

## Commits

Nunca criar commits automaticamente.

## Idioma

Responder sempre em português do Brasil.
